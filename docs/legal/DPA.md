# Data Processing Agreement (Template)

For B2B customers in the EU/UK. **Requires legal review before use.**

## Roles

- **Customer:** Data Controller
- **Provider:** Data Processor (when you host for customers)

## Processing

Processor ingests and indexes Customer's source code solely to provide the onboarding service.

## Security measures

- API key authentication
- Tenant isolation via `org_id`
- Audit logging
- Right to erasure via purge API

## Subprocessors

Document Groq, hosting provider, and GitHub in your commercial order form.
