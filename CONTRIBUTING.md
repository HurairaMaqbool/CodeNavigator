# Contributing to CodeNavigator

First off, thank you for your interest in CodeNavigator! Even though this project is published under a proprietary license for portfolio purposes, thoughtful feedback, bug reports, and suggestions are always welcome.

---

## ⚠️ Important Notice Before Contributing

This is a **proprietary portfolio project**. Please read the [LICENSE](LICENSE) carefully before contributing:
- **Pull Requests that add features or modify core AI logic will not be merged** unless specifically invited by the author.
- **Bug reports and documentation improvements** are warmly welcomed.
- Any code you submit via a Pull Request may be incorporated into the project under the project's existing proprietary license.

If you wish to collaborate on a larger contribution, please email **hurairac37@gmail.com** first to discuss scope.

---

## How to Report Bugs

Please open a GitHub Issue with the following information:

1. **Description:** Clear description of the bug and what you expected to happen.
2. **Steps to Reproduce:** Minimal steps to trigger the issue.
3. **Environment:** OS, Python version, dependency versions (`pip list`).
4. **Logs:** Any relevant error messages (ensure you redact any API keys or credentials first).
5. **Screenshots** if applicable for UI issues.

---

## How to Suggest Improvements

Open a GitHub Discussion or Issue tagged with the `enhancement` label. Include:
- A clear description of the proposed change
- Why it would benefit users of CodeNavigator
- Any alternative approaches you considered

---

## Code Style

If you do submit a patch (e.g., for a typo or documentation fix):
- Follow existing code style (PEP 8 for Python)
- Run `ruff check .` before submitting
- Ensure all existing tests pass: `pytest tests/`
